# Trinetra Hardware Adapters

This directory hosts specifications, schematics, and pinout profiles for external hardware sensors and interchangeable camera modules.

## Supported / Planned Interfaces
- Laptop Internal Webcams (UVC / DirectShow via OpenCV)
- External USB Wearable Cameras (Chest/Glasses mounted)
- Future Serial Microcontroller Adapters (ESP32, Arduino, Raspberry Pi Pico) for ultrasonic/LiDAR rangefinders.
