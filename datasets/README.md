# Trinetra datasets

Dataset contents are local and intentionally not committed. Each collection has `raw`, `processed`, `annotations`, `splits`, and `metadata` directories. Metadata must record provenance, licence, session/physical-source identifier, collection date, human verification, and preprocessing version.

Never use unconsented face images, silently captured camera footage, or unverified low-confidence predictions as labels. Keep independent test samples isolated from training and validation.
